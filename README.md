# 💰 Finance Tracker

A modern personal finance tracker built with **React, TypeScript, Vite, and Tailwind CSS**.  
Track your expenses, visualize analytics, set goals, and manage transactions with ease.  

Deployed on [Vercel](https://finance-tracker.vercel.app).

---

## 🚀 Features
- 📊 **Dashboard** – Overview of your balance, income, and expenses.  
- 📈 **Analytics** – Visual charts to understand spending trends.  
- 🎯 **Goals** – Set and track your financial goals.  
- 💳 **Transactions** – Add, edit, and delete transactions.  
- 📑 **Reports** – Export and view financial summaries.  
- ⚡ **Responsive UI** – Works seamlessly on desktop & mobile.
